Typeless Switch Windows 使用说明
================================

适用系统：Windows 10/11 x64

一、安装
--------

从本仓库 Releases 页面下载 TypelessSwitch-*-win-x64-setup.exe 并运行。
安装不需要管理员权限，也不会设置开机启动。

程序启动时会自动检查 GitHub 上的最新版本。发现更新后会询问是否下载，下载完成并通过 SHA-256 校验后，再询问是否打开安装程序。

执行操作时底部状态栏显示“取消”；操作完成、失败或取消后，按钮会变成“×”，点击即可关闭整个状态提示栏。

二、切换账号
------------

1. 打开 Typeless Switch。
2. 输入目标 Typeless 邮箱。
3. 点击“切换账号”。
4. 在弹出的 Typeless 登录页继续邮箱登录。
5. 输入邮件中的六位验证码。
6. 登录成功后窗口会自动关闭，Typeless 会使用新账号重新启动。
7. 程序重新读取邮箱和用户 ID，连续确认一致后才报告切换成功。

程序在修改前会自动备份本地状态。取消登录、Typeless 启动失败或身份不一致时，会先停止新进程再自动恢复原账号。

三、本地账号管理
----------------

首次打开后，当前账号会自动保存到 Windows 当前用户专属的加密会话库。
以后通过邮箱验证码登录的新账号也会自动加入“本地账号管理”列表。

选择账号并点击“切换到所选账号”即可恢复该账号。登录状态失效时，程序会提示重新验证。
列表同时显示账号健康状态和最近验证时间；旧版本迁移的账号会在首次成功切换后更新状态。
“移除本地记录”只删除本机记录，不会删除 Typeless 远程账号。

四、环境自检
------------

点击右上角“一键自检”，可检查 Typeless、WebView2、当前会话、DPAPI 账号库、本地存储和临时备份。
自检结束后可以复制脱敏报告；报告不包含邮箱、用户 ID、token、Windows 用户名或绝对路径。

五、更新程序
------------

程序启动后会自动检查更新，也可以点击窗口右上角的“检查更新”。
更新安装包暂存于 %LOCALAPPDATA%\TypelessSwitch\Updates，不会在未经确认时静默替换当前版本。

六、导出词典
------------

1. 确认窗口顶部显示正确的源账号。
2. 点击“导出到默认位置”，文件会保存到当前用户的“文档\Typeless Switch\Exports”；
   或点击“选择导出位置…”自行选择文件夹。
3. 导出后生成的 JSON 会自动成为待导入文件。

导出会一次生成 JSON、TXT、CSV 三个文件。JSON 是后续导入的标准文件。
每次导出前都会重新读取当前 Typeless 会话，并使用长期登录凭据；短期 access token 过期不需要重新登录。

七、导入词典
------------

1. 直接使用导出后自动选中的 JSON；也可以点击“使用默认文件”或“选择文件”。
2. 选择“快速批量”或“完整元数据”。
3. 点击“开始导入”。

快速批量模式会把词条按每批最多 200 个拆分，然后并行提交多个批次。
完整元数据模式也会并发执行，并保留语言、分类和替换规则。
每次导入前都会重新读取最新会话。遇到 401/403 时程序会重新同步并安全重试一次；重试会跳过已经成功写入的词条。

八、通用路径
------------

Typeless 数据通过 %APPDATA% 自动定位。
Typeless Switch 自身数据保存在 %LOCALAPPDATA%\TypelessSwitch。
加密账号会话保存在 %LOCALAPPDATA%\TypelessSwitch\AccountVault，并使用 Windows DPAPI CurrentUser 保护。
默认词典导出位置由 Windows“文档”目录动态确定，通常显示为“文档\Typeless Switch\Exports”。
操作期间的临时备份保存在 %TEMP%\typeless-switch-backup-*，切换成功或回滚完成后会自动删除。

不要在公共问题、截图或聊天中公开 token、user-data.json 或个人词典。
更完整的说明请查看仓库根目录中的 README.md。
