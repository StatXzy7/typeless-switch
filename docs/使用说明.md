# Typeless Switch v0.4.0 启动和使用说明

## 安装与启动

下载地址：https://github.com/StatXzy7/typeless-switch/releases/tag/v0.4.0

- 安装版：下载 `TypelessSwitch-0.4.0-win-x64-setup.exe` 并运行，随后从 Windows 开始菜单打开 **Typeless Switch**。已有旧版可直接覆盖安装。
- 默认程序位置：`%LOCALAPPDATA%\Programs\Typeless Switch\TypelessSwitch.exe`。
- 便携版：下载 `TypelessSwitch-0.4.0-win-x64-portable.zip`，完整解压到可写目录，再双击其中的 `TypelessSwitch.exe`；不要直接在 ZIP 中运行。
- Windows 10/11 x64；安装包与便携包自带 .NET 8 运行时。邮箱登录窗口需要 WebView2 Runtime。
- 程序内“使用说明”可打开本文件。无需 Node.js、终端命令或后台服务。

## 本次更新解决什么

旧版将字典 API 的 HTTP 403 全部显示成登录凭据无效。新版识别服务端错误码 `20006`（当前客户端不受支持），明确说明原因，不再为它重读会话并重复请求。

**本版本没有解除 Typeless 服务端对第三方客户端的限制。** 如果“检查词典连接”显示 `20006`，本工具仍无法直接导出云端词典；重新登录、换文件夹或管理员运行不能解决这项限制。账号状态可用只表示本地会话满足检查条件，不代表云端接口授权已经通过。

新增“检查词典连接”，只读取当前账号的词典，不导入、不写入词典。HTTP 401 仍会重读会话并重试一次；HTTP 403 会直接显示拒绝原因。失败信息不包含服务端原始响应或令牌。

## 已有备份：离线转换后使用官方导入

1. 在“词典迁移”中点击“选择文件”，选中已有的 `typeless-dictionary-export.json`。有默认备份时也可点击“使用默认文件”。
2. 点击“备份转官方 CSV”，选择保存位置。
3. 新版生成 UTF-8 无 BOM、没有表头的单列 CSV，保留中文、逗号和引号，去除重复词条并报告空词条数量。转换无需登录或联网，原 JSON 不会被修改。
4. 在官方 Typeless 客户端登录目标账号，打开 **词典 → 新建词条（New word）→ 导入 CSV（Import CSV）**，选择转换后的文件，检查预览并确认导入。

官方 CSV 只迁移词条文本。语言、分类、自动添加标记和替换规则不包含在 CSV 中，请保留原 JSON 完整备份。转换在后台执行，支持取消；会拒绝跨行词条、超过 32 MB 的 JSON 输入和超过 5 MB 的 CSV 输出。

官方指南：https://www.typeless.com/help/quickstart/history-and-dictionary

**没有已有 JSON 备份时，离线转换不能恢复云端词典。** 本版本不提供绕过客户端限制的功能，请通过官方支持渠道询问词典导出或授权迁移方式。

## 云端导出与原有功能

1. 先确认顶部账号，然后点击“检查词典连接”。只有连接成功时，再尝试云端导出。
2. “导出到默认位置”使用 Windows 文档目录下的 `Typeless Switch\Exports`，生成 JSON、TXT 和五列归档 CSV；该五列 CSV 请先由 JSON 转换成官方单列 CSV 后再使用官方导入。
3. “选择导出位置…”可以使用自选目录。接口拒绝时不会覆盖已有导出文件。
4. 账号管理、邮箱验证码切换、本地加密会话库、回滚、环境自检与更新检查仍保留。云端导入同样依赖服务端允许当前客户端。

## 遇到错误时

- `20006`：客户端不受支持；有备份时使用离线转换，没有备份时联系官方支持。
- HTTP 401：重试后仍失败，再在官方 Typeless 中重新登录。
- 其他 HTTP 403：服务端拒绝操作，先检查官方客户端能否访问同一账号的词典；不能仅据此认定登录过期。
- 本地文件权限错误：改用可写目录，并检查目标文件是否被其他软件占用。
- 需要本地诊断信息时点击“一键自检”，报告会过滤账号信息和令牌；该自检不验证云端授权。

## 更新与数据

在程序中点击“检查更新”，或从上述 Release 页面下载新版。更新下载会核对 SHA-256。程序不会静默安装更新。

账号会话存放在当前 Windows 用户的加密账号库中；程序更新不需要删除账号记录或词典备份。词典文件属于私人数据，请勿上传到公开 GitHub 仓库。

此安装包尚无商业代码签名；请核对 Release 中的 SHA-256 校验文件。本项目是独立工具，不是 Typeless 官方软件。
